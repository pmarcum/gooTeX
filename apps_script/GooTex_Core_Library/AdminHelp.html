🔧 Administrator Manual

One-time system setup and ongoing administration. Regular authors do not need this — direct them to the User Guide.

Research Group:

1. One-Time System Setup

Performed once per research group installation. Not repeated for each new paper.

Step 1: Make a copy of the GooTeX template
Make a copy of the public GooTeX template document in Google Drive. The copy will already have the GooTeX_Core library linked and the Config.gs and Code.gs script files in place.

GooTeX_Core is the shared library that provides the GooTeX engine. Code.gs is a lightweight attached script whose sole purpose is to load GooTeX_Core into the document and pass it the local configuration.

Open Extensions > Apps Script and fill in your group's values in Config.gs (see Step 2).
Step 2: Configure Config.gs
In the attached script's Config.gs, set the following values:

GOOTEX_SERVER_URL — VM server URL
GOOTEX_CREDENTIAL — must match GOOTEX_SECRET on the VM
BIBMAN_CREDENTIAL — BibMan credential (if BibMan is deployed)
GEMINI_API_KEY — Google AI Studio API key
GOOTEX_ATTACHED_VERSION — set to 1
GOOTEX_TEMPLATE_URL — the "make a copy" URL of THIS template, your copy from Step 1 (it ends in /copy). It is shown to users when their attached script needs updating, and it is how GooTeX recognises the template (Step 3).
Step 3: Open the Control Panel once in the template
With GOOTEX_TEMPLATE_URL set, open GooTeX > Control Panel in the template. GooTeX marks the template with its own Doc ID (a hidden mark, see "New Papers and Copies" below). Every copy of the template inherits that mark, and that is what lets a new paper use GooTeX.
Step 4: Verify
Run GooTeX > Admin Only > Check System Status. All items should show ✅, and This Doc should say this group's template.

2. New Papers and Copies

Every GooTeX Doc carries a hidden mark (its lineage): the Doc ID it was started from. Nobody sees it in the Doc, and deleting text does not remove it. Before the Control Panel opens, GooTeX checks it:

  • The mark is this Doc's own ID: GooTeX works.
  • The mark is the template's ID (a new copy of the template): GooTeX replaces it with this Doc's own ID, once, and works.
  • This Doc is the template: GooTeX marks it with its own ID and works.
  • Anything else (a copy of another paper, or a Doc not made from the template): the Control Panel does not open, and a message explains why. The server refuses such a Doc too.
New papers always start from the template (so they also get its latest updates). Copying an existing paper gives a Doc in which GooTeX is turned off; to reuse an old paper, make a copy of the template and paste the text in.

Papers started before Core 6

A paper started before GooTeX Core 6 has no mark yet, so GooTeX is off in it until it is marked once, by hand: in that paper, open Extensions > Apps Script, add a script file named MarkPaper, paste in apps_script/tools/MarkPaper.gs from the GooTeX repository, run markThisPaper, then delete the MarkPaper file again. Only mark Docs that really are your group's papers.

Moving to a new template

Papers keep working: each carries its own ID. Copies of the old template keep working too, because their Config.gs still points at the old template.

3. Managing Co-Author Access

There is no access list: anyone who can edit a GooTeX Doc can use GooTeX on it.

Add: Use GooTeX > Utilities > Invite Co-Author — it gives the person edit access to the Doc and its project folder, without sending any email, and shows an invitation text to copy into your own email. (Sharing the Doc and folder by hand works just as well.)
Remove: Stop sharing the Doc (and its folder) with them.

4. Troubleshooting

🅰️ Compiler Server Offline

The server restarts automatically after most failures. If it remains offline after 30 seconds, the VM administrator will need to restart the service manually.

🅱️ Reset Connection

Run GooTeX > Admin Only > Reset Connection after updating credentials in Config.gs, or any report of stale sidebar behavior.

🅲️ Credentials Not Working

If Check System Status shows a credential missing or the server returns 403 errors, verify the values in Config.gs and run Reset Connection afterward.

🅳️ Image Issues

Images over 1.5MB are compressed automatically on first compile. Add _NOCOMPRESS to a filename to prevent compression. Manual compression is available via GooTeX > Utilities > Compress Image.
