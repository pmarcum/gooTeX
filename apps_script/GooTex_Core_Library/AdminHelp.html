🔧 Administrator Manual

One-time system setup and ongoing administration. Regular authors do not need this — direct them to the User Guide.

Research Group:

1. One-Time System Setup

Performed once per research group installation. Not repeated for each new paper.

Step 1: Make a copy of the GooTeX template
Make a copy of the public GooTeX template document in Google Drive. The copy will already have the GooTeX_Core library linked and the Config.gs and Code.gs script files in place.

GooTeX_Core is the shared library that provides the GooTeX engine. Code.gs is a lightweight attached script whose sole purpose is to load GooTeX_Core into the document and pass it the local configuration.

Open Extensions > Apps Script and fill in your group's values in Config.gs (see Step 2).
Step 2: Configure Config.gs
In the attached script's Config.gs, set the following values:

GOOTEX_SERVER_URL — VM server URL
GOOTEX_CREDENTIAL — must match GOOTEX_SECRET on the VM
BIBMAN_CREDENTIAL — BibMan credential (if BibMan is deployed)
GOOTEX_ACCESS_SHEET_ID — access spreadsheet ID (see Step 3)
GEMINI_API_KEY — Google AI Studio API key
GOOTEX_ATTACHED_VERSION — set to 1
GOOTEX_TEMPLATE_URL — the "make a copy" URL of THIS template (shown to users when their attached script needs updating)
Step 3: Create the access spreadsheet
Run GooTeX > Admin Only > Initialize Drive Folder.
A GooTeX_Access spreadsheet will be created and its file ID displayed.
Copy that ID into GOOTEX_ACCESS_SHEET_ID in Config.gs.
Add authorized user emails to the allowed_users tab, one per row.
Step 4: Verify
Run GooTeX > Admin Only > Check System Status. All items should show ✅.

2. Managing Co-Author Access

Add: Use GooTeX > Utilities > Invite Co-Author — Drive access, whitelist entry, and invitation email are handled automatically.
Remove: Open the GooTeX_Access spreadsheet, delete the email from the allowed_users tab, then run GooTeX > Admin Only > Reset Connection to clear the cached access list.

3. Troubleshooting

🅰️ Compiler Server Offline

The server restarts automatically after most failures. If it remains offline after 30 seconds, the VM administrator will need to restart the service manually.

🅱️ Reset Connection

Run GooTeX > Admin Only > Reset Connection after adding or removing users, updating credentials in Config.gs, or any report of stale sidebar behavior.

🅲️ Credentials Not Working

If Check System Status shows a credential missing or the server returns 403 errors, verify the values in Config.gs and run Reset Connection afterward.

🅳️ Image Issues

Images over 1.5MB are compressed automatically on first compile. Add _NOCOMPRESS to a filename to prevent compression. Manual compression is available via GooTeX > Utilities > Compress Image.
