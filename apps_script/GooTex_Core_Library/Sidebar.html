💻 Local Compilation on Your Own Laptop (Optional)
For faster builds and offline use, install the local compiler:

Step 1 — Install pipx (one-time-only task, cross-platform commands):
pip install pipx
pipx ensurepath

Step 2 — Restart your terminal, then:
pipx install git+https://github.com/pmarcum/gooTeX.git

Step 3 — Launch any time by typing:
gootex-gui

No admin privileges required. Works on Mac, Windows, and Linux.
