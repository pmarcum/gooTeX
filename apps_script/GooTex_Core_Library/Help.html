User Guide

Write your paper in Google Docs — GooTeX handles the LaTeX compilation when you hit the Compile button.

📄 Starting a New Paper

  1. Create a folder in Google Drive for the paper.
  2. Place this Google Doc inside that folder, or any subfolder of it.
  3. Place your image files, .bib file, and any supplemental .tex files in that folder or its subfolders.
  4. Open GooTeX > Control Panel and click Compile.
The folder does not need any special setup — GooTeX finds the server configuration automatically.

🚀 The Control Panel (Sidebar)

Open via GooTeX > Control Panel.
  • 🟦 REFRESH: Scans the document for new citations, labels, and text changes without compiling a PDF.
  • 🟩 COMPILE: Sends the document to the server and builds the full PDF.
  • ¶ MARKERS: Toggles tiny gray paragraph numbers in the text. Useful for locating LaTeX errors.

📊 The Status Bar (HUD)

Located at the bottom of the sidebar, updated after every compile:

w:2450 | p:12 | Joh... | 4:30p
  • w: Word count (approximate).
  • p: Page count from the last successful PDF.
  • User: Who triggered the last compile.
  • Time: Timestamp of the last PDF.

📂 The Tabs

1. Log (The Debugger)

Displays output from the LaTeX compiler. Check here when a compile fails.

  • Click an Error: Jumps the cursor to the exact code block in the document where the error occurred.
  • The 🤖 Button: Click the robot icon next to a cryptic error — Gemini AI will analyze the context and suggest a fix.
Tip: The more paragraph breaks in the document, the more precisely GooTeX can locate errors.

2. Refs (Bibliography Manager)

Displays and manages the bibliography for the paper. Two sources are supported:

Option A — Local .bib file
Place a .bib file anywhere in the project folder. Reference it in the document with:
\bibliography{MyLibrary}

GooTeX finds the file automatically and populates the Refs tab from it.
Option B — BibMan (optional)
BibMan is a shared bibliography manager that your research group may have set up. If available, reference it with:
\bibliography{bibman:LibraryName}

GooTeX connects to BibMan automatically, retrieves only the entries cited in the document, and refreshes the Refs tab when the library changes. No local .bib file needed.
Ask your system administrator whether BibMan is available for your group and what the library name is.

Regardless of which option is used, the Refs tab works the same way:

  • ⭐ Stars: Items highlighted in yellow/gold are cited at least once in the document.
  • Insert Cite: Place the cursor where the citation should go, type \citep{, then click Cite next to the desired reference.
  • Smart Filter: Use these prefixes in the search bar:
Authora:smith
Yeary:2020 (Exact), y:2020- (Since), y:2020-2025 (Range)
Titlet:galaxies starformation
Journalj:apj, j:apj 630 (Vol), j:apj 630 56 (Page)
AnyType words without prefix to search raw text.
Comboa:smith t:galaxies y:2000-

3. Figs & Tabs (Assets)

Tracks every \begin{figure} and \begin{table} in the text.

  • Thumbnails: Preview of the figure image if available in Drive.
  • REF Button: Inserts a cross-reference (e.g., Fig.~\ref{fig:label}).
  • SEC Button: Inserts a reference to the section containing that figure.

4. { } Snip (Templates)

Click a button to insert complex LaTeX templates instantly.

  • My Shortcuts: Click + Add to save frequently used LaTeX blocks.
  • Built-in: Standard templates for Figures, Tables (deluxetable), and Math.

📂 File Organization

Where to save this document

The document can live anywhere in Google Drive. GooTeX finds the server configuration automatically. Placing the document inside the project folder (or a subfolder) is recommended so all co-authors with folder access can compile.

👥 Co-Authors: Editor access to the project folder is required. If invited via GooTeX > Utilities > Invite Co-Author, access is granted automatically.

Where to save supplemental files

GooTeX searches for images, .tex files, and .bib files in the project folder and all its subfolders, as well as the folder containing the Google Doc. The system Compiled folder is ignored automatically.
  • Put images in an Images/ subfolder and chapters in a Chapters/ subfolder — GooTeX will find them.
  • Keep images as real files rather than shortcuts — shortcuts may not preview correctly in the sidebar.

🛠️ Utilities

  • 📉 Compress Image: Manually compress a specific image on Drive. Images over 1.5MB are also compressed automatically on first compile. Originals are preserved with an _UNCOMPRESSED suffix. Add _NOCOMPRESS to a filename to prevent compression entirely.
  • 📝 Word Count: Counts words in selected text.
  • 🤝 Invite Co-Author: Grants Drive access, adds the user to the compiler whitelist, and sends an invitation email.
  • 📄 Compiled Files: After each successful compile, the PDF, log, bibliography, and processed .tex file are saved automatically to a Compiled/ subfolder.

⌨️ Shortcuts

  • Refresh: Alt + R
  • Compile: Alt + Enter
(on Mac, Alt is Option)
